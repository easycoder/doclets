**Three judgement calls worth flagging**

1. **The manifest is `manifest.json`, not `manifest.webmanifest`.** This host serves `.json` as `application/json`, which every browser accepts for a manifest; `.webmanifest` is unmapped here, so it would come back as `application/octet-stream` and be rejected. Getting it right would have meant an `AddType` in `.htaccess`, which only ships with `--infra`.
2. **The shell is cached without its query string.** The loader fetches `doclets.allspeak?v=` cat now — a new URL every page load — so keying on the full URL would grow the cache without bound.
3. **I found a hole in my own first cut, before deploying.** It treated every same-origin *navigation* as shell, which would have cached whatever `/token` and `/key` returned — and `.htaccess` rewrites those two onto `secrets.php`. Now only the known shell paths are intercepted.
